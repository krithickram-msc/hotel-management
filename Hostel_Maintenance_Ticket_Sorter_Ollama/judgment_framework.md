# Judgment Framework

| Area | Model decision | Python check | Human checkpoint |
|---|---|---|---|
| Room | Extract explicit room | Validate block A-D and room 01-20 | Ask for clarification if absent |
| Issue | Choose category | Validate allowed category | Review unusual cases |
| Urgency | Identify safety risk | Safety-word net can promote urgency | Warden reads every urgent ticket |
| Duplicate | Identify same room + issue | Compare against open and current tickets | Warden decides follow-up |
| Routing | Suggest team | Fixed routing dictionary | Warden assigns work |
| Closure | No authority | Never closes tickets | Warden closes work |
